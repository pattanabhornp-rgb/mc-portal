# MC Portal

เว็บต้นแบบสำหรับจัดการการประชุมคณะกรรมการจัดการ

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้โดยตรง ไฟล์โลโก้ `innobic-logo-white.png` ต้องอยู่ในโฟลเดอร์เดียวกัน

## สถานะต้นแบบ

ข้อมูลตัวอย่างและรายการที่เพิ่มเก็บใน localStorage ของเบราว์เซอร์ ขณะนี้ยังไม่มีระบบยืนยันตัวตนและควบคุมสิทธิ์จริง การจัดประเภทวาระลับในต้นแบบเป็นเพียงป้ายในหน้าจอเท่านั้น ยังไม่ควรใช้เก็บข้อมูลการประชุมจริงหรือข้อมูลลับ

การอัปโหลดเอกสาร การแจ้งเตือน และบริการ AI ยังไม่ได้เชื่อมต่อ
